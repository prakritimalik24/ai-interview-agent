# AI Assistance & Prompts

AI tools were used selectively during development, mainly for debugging,
understanding API integration, and improving parts of the implementation.

The core application structure, UI design, interview flow, candidate flow,
and component organization were developed and modified manually.

## Prompts Used

# 1. Gemini API Integration

> How can I integrate the Google Gemini API into a React application?


# 2. Environment Variables

> How should I store my Gemini API key using environment variables and make sure it is not committed to GitHub?

# 3. API Debugging

> My POST request to my evaluation API is returning a 500 error.


## 4. AI Evaluation Prompt

> Help me design a prompt for Gemini that evaluates a candidate's technical interview answers based on correctness, clarity,completeness, and technical understanding.

# 5. Markdown Rendering

> My AI-generated evaluation contains Markdown headings, bold text, and bullet points. How can I render this properly in a React application?


<br/>

AI assistance was primarily used as a development aid for:

- Understanding Gemini API integration
- Debugging API and environment-variable issues
- Structuring the Gemini evaluation prompt
- Rendering AI-generated Markdown
